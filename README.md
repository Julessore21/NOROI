# NOROI — thème Shopify

Thème Online Store 2.0 basé sur le [Skeleton theme](https://github.com/Shopify/skeleton-theme) de Shopify.

Connecté à Shopify via l'intégration GitHub (branche `main`).

## Dev local

```bash
npm install -g @shopify/cli
shopify theme dev --store <ta-boutique>.myshopify.com
```
